# Feature — Personnalité qui évolue

Parent : [../../MASTER.md](../../MASTER.md)

## Point de départ
Jauges court terme (énergie, faim, humeur, affection) sans mémoire longue.

## Objectif
Un lien qui se construit sur des semaines et débloque des comportements, et un carnet de vie.

## Décisions
- `Bond` (points cumulés) → paliers : 0 Nouvelle tortue, 1 Copain (≥ 60), 2 Ami (≥ 250),
  3 Meilleur ami (≥ 700), 4 Inséparable (≥ 1500)
- Gains : câlins (+1 / 10 s), temps passé ensemble éveillés (+0,2 / min d'activité), jeux de souris (+3),
  cadeau accepté (+4), visite réussie (+2) ; pertes : lancer (−2), clics en rafale (−1), absence (−3 %/jour)
- Débloqués : 1 → te suit parfois ; 2 → dort contre ta souris, apporte des cadeaux ; 3 → accueil
  en courant, yeux cœurs plus facilement ; 4 → triste quand tu pars, danse de joie à ton retour
- Carnet : journal local (200 entrées max, entrées privées jamais envoyées), stats par jour et totales,
  collection de souvenirs ; menu « Carnet » (résumé + dernières entrées) ; page web publique
  (feature bande) sans les entrées privées
